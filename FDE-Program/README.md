# FDE Program

Training plans for the anyops.ai Forward Deployed Engineer (FDE) program, for new grads and early-career engineers.

| Plan | Length | Hours | File |
|---|---|---|---|
| 12-week | 12 weeks, full-time (40 h/week) | 480 | [FDE_12Week_Plan.md](FDE_12Week_Plan.md) |
| 24-week | 24 weeks, full-time (40 h/week), deeper | 960 | [FDE_24Week_Plan.md](FDE_24Week_Plan.md) |

Both plans follow the same order: software development and AWS cloud, then applied AI (the largest block), then customer-facing scoping, with projects and a customer-skills thread throughout. Labs use AWS as the primary cloud and provider-neutral AI tooling with Claude as the default. No certifications are required.

Status: draft for review. Hour figures, tool status and the customer-skills methods are labeled as sourced, judgment or assumption inside each plan, and a pilot is recommended before relying on them.
